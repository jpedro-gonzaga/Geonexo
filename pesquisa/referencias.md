# Referências de pesquisa

Leituras levantadas no chat. A coluna de aplicação descreve ideias a testar. Consulte amostra, modalidade, métrica e protocolo no artigo antes de usar números no pitch. Alguns textos integrais têm acesso restrito.

| Linha | Leitura | Aplicação |
| --- | --- | --- |
| Reconstrução com incerteza | [Conditional Flow Matching for Uncertainty Aware Borehole Image Inpainting](https://doi.org/10.1111/jpg.70093) | Explorar múltiplas reconstruções. A modalidade estudada é microrresistividade elétrica. |
| Carbonatos do pré-sal | [The use of convolutional neural networks to predict carbonate dissolution features in acoustic borehole images](https://doi.org/10.1007/s12145-026-02097-8) | Relacionar análise de feições à modalidade acústica em dados brasileiros. |
| Continuidade estrutural | [Reconstruction of borehole image gaps via adversarial edge learning](https://academic.oup.com/jge/article/23/3/703/8419684) | Avaliar preservação de bordas e máscaras realistas. |
| Interpretação de perfil | [Automated Borehole Image Interpretation Using Computer Vision and Deep Learning](https://doi.org/10.2118/218881-PA) | Entender classificação de feições em imagens elétricas. |
| Medicina | [Pixelwise Uncertainty Quantification of Accelerated MRI Reconstruction](https://pubmed.ncbi.nlm.nih.gov/41647209/) | Investigar incerteza por pixel. |
| Petrofísica multimodal | [Rede SOM para Aprendizado de Representações Multimodais com Aplicação em Petrofísica](https://ojs.sba.org.br/index.php/cba/article/view/4398) | Investigar relações entre imagem acústica e outros perfis. |
| Conhecimento geológico | [InpAS](https://www.sciencedirect.com/science/article/pii/S2352854026000604) | Incorporar informação sedimentar ao preenchimento. |
| Lacunas reais | [Real Missing-Region-Constrained Self-Supervised Inpainting](https://www.mdpi.com/2076-3417/16/14/7320) | Treinar com padrões de falta coerentes com aquisição. |
| Perfil e interpretação | [FracLogGPT](https://www.mdpi.com/2079-9292/15/1/127) | Explorar evolução para descrição assistida. |
| Alucinação médica | [Tackling Hallucination](https://papers.miccai.org/miccai-2025/0899-Paper4526.html) e [Hallucination Index](https://pubmed.ncbi.nlm.nih.gov/40166669/) | Estudar estruturas artificialmente inseridas. |
| Aplicação na África Oriental | [Geophysical Journal International](https://academic.oup.com/gji/article/235/1/942/7223463) | Entender o uso da interpretação para decisões de perfuração. |
