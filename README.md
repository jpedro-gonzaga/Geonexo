# Geonexo

Base de trabalho do Desafio 07 do hackathon de Indústria e Energia. A proposta é ajudar geólogos a ler imagens acústicas das paredes de poços do pré-sal, estimar trechos ausentes, mostrar a incerteza e priorizar intervalos para revisão.

| Pasta | Conteúdo |
| --- | --- |
| [docs](docs/) | Enunciado, decisões da conversa e contexto de Sergipe |
| [pesquisa](pesquisa/) | Artigos, referências técnicas e dados candidatos |
| [prototipo](prototipo/) | Escopo, plano de implementação e critérios de validação |
| [pitch](pitch/) | Fala de cinco minutos, sequência de slides e cenários de produtividade |
| [visuais](visuais/) | Enunciado com contatos ocultos, SVGs recuperados e galeria HTML |

**Estado do projeto** · documentação e demonstrações conceituais. A galeria funciona localmente no navegador. Abra [visuais/index.html](visuais/index.html) em um clone do repositório. O visualizador para dados reais e a avaliação experimental estão em planejamento.

Geonexo é o nome de trabalho adotado para o repositório e o roteiro. GeoEcho AI e GeoVision aparecem no debate original. A decisão de marca segue aberta.
